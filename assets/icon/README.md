The rounded frame is an aircraft cabin window. Its dark opening and level fill suggest a simple quota gauge, while the fill color identifies the current state. The frame has a dark outer edge and a pale inner band so it stays visible on light and dark tray backgrounds. Run `python assets/icon/render.py` from the repository root to regenerate the SVG, PNG, favicon and tray `.ico` files. The tray uses the `state-*` files: PNG on Linux and macOS, ICO on Windows.
